# Data

Generated data lives here. Do not hand-edit these files.

| Path | Source | Licence |
|---|---|---|
| `registry/cosing/annex_II..VI.csv` | European Commission CosIng export | CC BY 4.0 |
| `registry/cosing/ingredients.json` | CosIng Checker mirror (EU 2025/1175 glossary + CosIng function records) | CC BY 4.0 / mirror declaration |
| `registry/cosing/manifest.json` | generated by `scripts/fetch_registry.py` | metadata |
| `products/<key>.json` | Open Beauty Facts (or the source named in `source`) | ODbL 1.0 |
| `catalog/products.json` | owner-authorized curated product and formula records | ODbL 1.0 / DbCL 1.0 |
| `catalog/products.md` | generated, human-readable view of the curated catalog | ODbL 1.0 / DbCL 1.0 |
| `shelf/<name>.json` | optional public shelf; personal by default | owner's metadata |

Attribution and share-alike obligations are in
[`../DATA-LICENSE.md`](../DATA-LICENSE.md).

Regenerate the registry snapshot with:

```bash
python scripts/fetch_registry.py
```

The script rate-limits itself to 120 requests/minute. It writes the official
annex CSVs, a stripped content hash for each annex, and a merged ingredient
catalogue. Raw scraped panels and the personal shelf live in `../local/`,
which is gitignored and never published. Use `skincare import --file
local/imports/owned-inventory.json --shelf default` for a private batch
inventory. Product records and source observations stay below `local/`.

The public catalog is a deliberate exception: after owner authorization,
`python scripts/publish_catalog.py` reads the private
`local/exports/owned-inventory.json` export and writes only product names,
ordered formula tokens, source provenance, confidence and uncertainty to
`catalog/products.json`. It omits shelf names, ownership counts, wishlist
entries, personal notes and raw captures. A product without a formula is still
listed with its formula marked unavailable.
